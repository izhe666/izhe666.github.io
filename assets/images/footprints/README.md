Each city can also use multiple media entries in `_data/footprints.yml`:

```yaml
media:
  - type: "image"
    src: "/assets/images/footprints/city-1.jpg"
  - type: "image"
    src: "/assets/images/footprints/city-2.jpg"
  - type: "video"
    src: "/assets/images/footprints/city-video.mp4"
```
